# Spainza Portal

Клиентский портал Spainza: сайт, личный кабинет, документы, сообщения и управление кейсами.

## Локальный запуск

1. Установите Python-зависимости:

```powershell
pip install -r requirements.txt
```

2. Установите frontend-зависимости:

```powershell
npm install
```

3. Запустите backend:

```powershell
python run_server.py
```

Если настроен `TELEGRAM_BOT_TOKEN`, во втором терминале запустите Telegram worker:

```powershell
python run_telegram_worker.py
```

Worker обрабатывает команды бота, очередь уведомлений, напоминания, тихие часы и ежедневные дайджесты. При первом запуске он автоматически создаёт недостающие таблицы и колонки SQLite.

4. Откройте сайт:

```text
http://127.0.0.1:5000
```

## Полезные команды

Собрать CSS:

```powershell
npm.cmd run build:css
```

Запустить проверки:

```powershell
npm.cmd test
```

Проверить production npm-зависимости:

```powershell
npm.cmd audit --omit=dev
```

## Важные файлы

- `.env.example` - пример настроек для локального запуска.
- `.env.production.example` - пример настроек для сервера.
- `docker-compose.production.yml` - запуск на сервере.
- `backend/app.py` - основной Flask-сервер.
- `frontend/lk/` - страницы личного кабинета.

## Telegram-ассистент

После привязки аккаунта клиент может посмотреть текущие задачи, документы и этапы кейса, открыть двуязычный FAQ и отправить менеджеру структурированный вопрос. Настройки позволяют отдельно управлять сообщениями, документами, изменениями кейса, напоминаниями, тихими часами и дайджестом.

Документы и другие чувствительные данные загружаются только через защищённый личный кабинет. Бот показывает сводку и ведёт клиента на соответствующую страницу портала.

Напоминания создаются за три дня до срока, в день срока и после просрочки. Тихие часы `22:00–08:00` и время дайджеста интерпретируются в часовом поясе `Europe/Madrid`; срочные события не откладываются.

## Что не нужно добавлять в git

- `.env` и другие реальные файлы с паролями.
- `storage/` с загруженными файлами пользователей.
- `database/*.db` с локальной базой.
- `.vs/`, `.vscode/`, `.idea/` с настройками редакторов.
